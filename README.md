# 📺 Netflix Data Analysis Project

## 📌 Project Overview
This project involves analyzing the Netflix titles dataset to extract meaningful insights using Python. We cleaned, explored, and visualized key aspects of the data such as content type distribution, ratings, country-wise trends, genres, and temporal content patterns.

## 🛠️ Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Jupyter Notebook
- VS Code

## 🧹 Data Cleaning
- Handled missing values in critical columns like `director`, `cast`, `country`
- Removed duplicates
- Converted `date_added` to datetime format
- Extracted `year`, `month`, and `day` from `date_added`
- Split genres into lists for analysis

## 📊 Key Insights
- Netflix has more **movies** than TV shows in its catalog
- Most content is rated **TV-MA** and **TV-14**
- **United States**, **India**, and **UK** lead in content production
- Netflix added the most content in **2019–2020**
- **Dramas**, **Comedies**, and **Documentaries** are the top genres
- Top directors include **Rajiv Chilaka**, **Martin Scorsese**, and **Steven Spielberg**

## 📈 Visualizations
- Bar plots for content type, ratings, top countries
- Line plots for yearly and monthly content trends
- Bar plots for top genres and top directors

## ✅ Conclusion
This project provided hands-on experience in real-world data cleaning and EDA using Python. The analysis highlights Netflix’s focus on mature, drama-heavy content and its expansion over time across multiple regions and genres.
